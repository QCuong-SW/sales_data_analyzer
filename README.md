# Sales Data Analyzer

A Python project using Pandas to analyze sales data and practice essential data analysis techniques.

## Tech Stack
- Python
- Pandas
- CSV

## Features
- Data inspection and filtering
- Sales calculations and aggregation
- Data merging and cleaning
- Product, category, and regional sales analysis
- Monthly sales trend analysis

## Getting Started

```bash
pip install pandas
```

Run the analysis script or notebook in the project directory.

## Learning Goals

Build a strong foundation in data analysis and prepare for future Exploratory Data Analysis (EDA) and Machine Learning projects.
